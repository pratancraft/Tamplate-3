WEBSITE PROFIL BISNIS — RUANG USAHA

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder website_profil_bisnis di VS Code.
3. Klik kanan index.html lalu pilih Open with Live Server (jika ekstensi Live Server terpasang).
   Alternatif: klik dua kali index.html untuk membukanya di browser.

BAGIAN YANG PERLU DIGANTI SEBELUM DIPUBLIKASIKAN
1. Nama bisnis: cari dan ganti teks "RUANGUSAHA" / "Ruang Usaha" di index.html.
2. Nomor WhatsApp: ganti 6281234567890 pada index.html dan script.js dengan nomor bisnis Anda.
   Gunakan kode negara 62 tanpa tanda +, spasi, atau angka 0 di depan.
3. Email dan alamat: ubah di bagian Kontak.
4. Produk: ubah nama, harga, kategori, dan foto di bagian Galeri Produk.
5. Foto: ganti URL gambar pada atribut src dengan URL foto Anda.
6. Lokasi: ganti alamat dan URL peta Google Maps pada bagian Lokasi.
7. Warna dan tampilan: ubah nilai variabel warna di bagian paling atas style.css.

STRUKTUR FILE
- index.html : isi dan struktur halaman
- style.css  : desain, warna, dan tampilan responsif
- script.js  : menu mobile, filter galeri, dan fungsi WhatsApp

CATATAN
- Website ini adalah template statis, tidak memerlukan database.
- Form kontak membuka WhatsApp; data tidak disimpan ke server.
- Foto contoh membutuhkan koneksi internet.
- Nomor WhatsApp dan informasi bisnis masih berupa contoh. Ganti sebelum website dipublikasikan.
